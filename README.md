This project focuses on performing a comprehensive sentiment analysis on customer reviews of ChatGPT to better understand user satisfaction and common feedback themes. The main objective is to evaluate the overall sentiment expressed in the reviews, identify positive and negative patterns, and extract frequently mentioned keywords that explain user perceptions. The dataset includes textual reviews, ratings, and dates, which were first cleaned and prepared by handling missing values, standardizing formats, and preprocessing the text to ensure accuracy and consistencyOnce the data was prepared, exploratory data analysis (EDA) was conducted to uncover initial trends in sentiment, review length, and keyword frequency. Visualizations such as histograms, bar charts, and word clouds helped reveal patterns and guided the analytical direction. The core analysis used NLP techniques, including TextBlob or VADER, to calculate sentiment polarity and subjectivity. Reviews were categorized as positive, neutral, or negative, and compared with user ratings to understand alignment. Keyword extraction and frequency analysis were also applied to highlight the most mentioned praises and complaints.
The findings were translated into actionable insights that align directly with the project’s objectives—such as identifying the features users appreciate most, recurring issues, and general sentiment distribution. Throughout the project, clear storytelling and structured explanation were prioritized, using visuals only where they strengthened the narrative. The codebase is clean, readable, and well-commented, with the notebook organized in logical sections from data preparation to insight generation, ensuring seamless execution from start to finish.
This project was built using Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, TextBlob/VADER, and WordCloud, and the repository includes the dataset, analysis notebook, visual outputs, and a requirements file. It provides a solid foundation for future enhancements, including building an ML-based sentiment classifier, deploying an interactive dashboard, or expanding the dataset for deeper insights.
